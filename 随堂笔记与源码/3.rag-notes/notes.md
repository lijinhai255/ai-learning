## RAG 模块化检索流水线

Retrieval-Augmented Generation（检索增强生成）

处理流水线：
1. 离线处理
2. 检索服务

离线处理：student.csv 先切片文档分片，然后将分片进行向量索引化，然后向量存储于向量数据库
检索处理：用户提问小明成绩多少，检索匹配度高的向量，重新排序把相关度提上来，将相关的切片拼接到用户提示词给到模型输出答案

## 知识库构建——离线索引流水线设计

1. 文档加载【拓展：图片、视频 多模态】
2. 文档切片
3. 向量化
4. 向量存储


## 开发流程

1. 加载文档
    - document loader
2. 文档分片
3. 分片向量化，用对应的向量化模型【向量化模型的作用就是将文档分片转为多维向量】
    - doubao-embedding-vision
4. 暂时性的存在内存中 Memory
   永久性的存在向量数据库中
    - pgvector
    - qdrant
    - milvus

检索时将问题先通过向量匹配，结果拼接提示词，给到模型最终输出
