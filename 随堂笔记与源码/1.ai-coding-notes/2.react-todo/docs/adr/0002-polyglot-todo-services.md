# ADR-0002：以独立应用实现 Spring Boot 与 FastAPI Todo 服务

- 日期：2026-09-12
- 状态：已接受

## 背景

仓库已有 NestJS Todo API，服务端行为简单且以进程内数据为边界。需要向 Java Spring Boot 和 Python FastAPI 开发者提供等价实现，同时不改变现有前端和 NestJS 应用。

## 决策

在 `apps/api-spring` 与 `apps/api-fastapi` 建立两个独立应用，复用现有 HTTP 契约，但不引入跨语言运行时或数据库。每个应用各自维护领域模型、内存仓储、HTTP 层和测试。

## 影响

- 优点：启动、依赖和测试彼此隔离；示例代码贴近各自生态；可直接比较不同框架的实现。
- 代价：两套服务存在少量契约重复，需要通过契约文档和行为测试保持一致。
- 后续：若引入持久化、鉴权或版本化 API，应先更新契约并增加共享 schema/契约测试。
