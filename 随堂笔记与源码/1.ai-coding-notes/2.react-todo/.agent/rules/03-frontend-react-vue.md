# React 与 Vue 前端规范

## 共同约定

- 组件保持单一职责，页面负责编排，feature 负责业务状态，基础组件负责视觉和通用交互。
- 优先语义化 HTML、可访问名称、键盘操作、可见焦点和正确的表单标签。
- 加载、空、错误、成功四种状态都要有明确 UI；异步更新需防止竞态和重复提交。
- 状态放在离使用点最近的位置。跨页面共享状态需要说明生命周期、持久化策略和失效条件。
- 网络调用封装在 query/service 层，组件只消费类型化结果，不拼接 URL 或解析原始响应。

## React

使用函数组件和 Hooks。Effect 仅用于同步外部系统，派生数据优先通过计算获得。列表项使用稳定业务 ID 作为 key，事件处理函数保持可测试，表单控件明确受控或非受控策略。Context 只承载低频、跨树依赖，频繁业务状态采用专门 store 或 feature hook。

## Vue

使用 Composition API 与 `<script setup>`。可复用逻辑封装为 composable，组件通过明确的 props、emits 和 slots 通信。避免在模板中放置复杂副作用，响应式数据的边界和解包行为需在测试中固定。

## React 与 Vue 的一致性

同一业务 feature 在两套前端的用户行为、字段命名、错误码和无障碍语义保持一致。视觉差异只来自平台组件实现，业务规则复用 `packages/contracts` 与测试夹具。新增交互先在验收矩阵中定义跨框架共同场景。

## 性能与安全

以用户路径为依据测量性能，避免无证据的过早 memo、懒加载或状态拆分。渲染用户输入时使用框架默认转义，富文本必须经过白名单清洗。前端日志去除令牌、个人数据和完整响应体。
